## Short description (under 160 characters)

Free, open-source full-page screenshot extension for Chrome and Firefox. Capture, annotate, blur,
export PNG or PDF, record a tab. 100% local, no account.

## Long description

OpenScreenShot takes a screenshot of a whole scrolling web page in one click, then opens an editor
where you can crop, add arrows and text, number the steps, blur or black out private details, and
save the result as PNG, JPEG, WebP, or a multi-page PDF. The Chrome build also records the current
tab with auto-zoom at each click, a webcam bubble, and MP4 export. Everything runs on your device:
no account, no upload, no telemetry. MIT licensed. A separate npm package, `openscreenshot`, is a
local CLI and MCP server that takes website screenshots from a terminal, CI, or an AI agent.

Links: https://openscreenshot.app · https://github.com/PGHQdev/OpenScreenShot ·
https://www.npmjs.com/package/openscreenshot
